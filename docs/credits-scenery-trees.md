# Credits: scenery trees (trees-models variant)

`src/scenery/trees-models-data.js` packs four tree models from **Quaternius' Ultimate Nature pack**:
`CommonTree_1`, `CommonTree_3` (broadleaf) and `PineTree_2`, `PineTree_3` (pine).

- Author: Quaternius (https://quaternius.com/packs/ultimatenature.html)
- Licence: CC0 1.0 Universal (public domain dedication), per the pack's License.txt
- Taken from the pack's OBJ folder (October 2026), fan-triangulated, positions quantised to
  int16 and indices to uint16, grouped by material (wood, leaves, dark leaves); the game colours
  each part for the place. About 104 KB as a base64 data module.

Also considered: Kenney Nature Kit (CC0; too toy-like next to the fighters) and Poly Haven
trees (CC0; 0.3–17 M triangles each with alpha-cut textures, far too heavy).
